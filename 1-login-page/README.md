# Northstar sign-in

A responsive, centered sign-in page built with Next.js, React, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Use `npm run lint` to check the code and `npm run build` to create a production build. The sign-in and password-recovery controls are UI demonstrations and are not connected to an authentication service.
